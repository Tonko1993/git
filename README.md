2. COMMENT LANCER LE PROJET
- Installer Laragon (version Full recommandée) et lancer Laragon.
- Cliquer sur Start (Apache/Nginx + MySQL n’est pas obligatoire pour cet atelier). 
- Vérifier que le serveur fonctionne : ouvrir http://localhost/ dans le navigateur.
- Vérifier la version PHP : Menu Laragon → PHP → Version (choisir PHP 8.x si plusieurs versions disponibles).
